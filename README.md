# taskR

Simple CLI todo app written in Rust

## Usage
```
Usage: taskr [COMMAND]

Commands:
  add     Add task
  list    List tasks
  done    Complete or uncomplete selected task(s)
  edit    Edit selected task
  remove  Remove selected task(s)
  help    Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help
```
